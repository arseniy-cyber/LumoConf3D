# LumoConf3D — LUMO PC BUILDER

Веб-конфигуратор игровых ПК с интерактивной 3D-сценой, каталогом из 58 комплектующих, проверкой совместимости и отдельной панелью магазина. Цены и остатки стартового каталога демонстрационные. В карточках указаны источники характеристик и происхождение доступных материалов.

## Локальный запуск

Требуется Node.js 22.13 или новее. Проект проверен на Node.js 24.22.3 и npm 11.19.1.

```sh
npm ci
npm run db:migrate
npm run build
npm run dev:pages
```

Конфигуратор откроется на `http://localhost:8788/`, панель магазина на `http://localhost:8788/admin`. Для входа создайте владельца и привяжите TOTP по разделу [Локальный запуск](docs/BACKEND.md#локальный-запуск). Ключи Turnstile требуются для приёма заявок. Просмотр каталога, подбор, анализ и экспорт доступны сразу.

Для работы только с интерфейсом запустите `npm run dev`. Для Vite с локальным API установите `VITE_API_ENABLED=1` при старте Vite и запустите `npm run dev:api` в другом терминале.

## Проверки

```sh
npm test
npm run test:api
npx playwright install chromium
npm run test:browser
npm run build
```

Чтобы использовать системный Chromium, передайте `LUMO_CHROMIUM=/путь/к/chromium`. Для запуска браузерных сценариев на уже работающем приложении передайте `LUMO_BROWSER_URL`. Фактическое покрытие и ограничения перечислены в [отчёте](TEST_REPORT.md).
