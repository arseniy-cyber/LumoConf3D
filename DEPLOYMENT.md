# Развёртывание LUMO PC BUILDER

## Локальная установка

Выполните `npm ci`, `npm run db:migrate`, `npm run build` и `npm run dev:pages` из корня репозитория. Конфигуратор работает на порте 8788. Настройте `.dev.vars` по образцу `.dev.vars.example` и создайте первого владельца для работы с панелью. [Создание владельца и TOTP](docs/BACKEND.md#локальный-запуск)

## GitHub и Cloudflare

1. Проверьте ветку `development/lumo-builder` и выберите утверждённую ветку GitHub для выпуска.
2. В аккаунте владельца создайте D1 и укажите её ID в конфигурациях Wrangler. Выполните миграции для новой среды.
3. Подключите репозиторий в Cloudflare Pages. Корень сборки совпадает с корнем репозитория, команда `npm run build`, каталог вывода `dist`. Привязка D1 называется `DB`.
4. Установите независимые ключи для проверки паролей, ограничения частоты запросов и TOTP по эксплуатационной инструкции. Создайте владельца магазина. Для отдельного Worker выберите конфигурацию `wrangler.worker.jsonc` и тот же целевой ID D1 в данной среде.
5. Привяжите домен, проверьте адрес магазина, HTTPS, CSP, ограничение iframe и лимиты тарифа.
6. Подключите Turnstile и Telegram, если магазин готов принимать заявки. Проверьте сценарий заявки на утверждённой тестовой среде. [Пошаговая инструкция и лимиты](docs/BACKEND.md#подготовка-cloudflare-pages)

## Подключение каталога и магазинов

В панели добавьте товар, совместимость, размеры, дату и источник характеристик, цены и остатки, проверенные правообладателем фото и GLB. При массовом редактировании используйте экспорт и импорт JSON. Проверяйте посадку в целевых корпусах и сохраните ссылку на лицензию каждого файла. [Параметры товаров и файлов](docs/BACKEND.md#управление-товарами-и-файлами)

Создайте запись магазина с отдельным slug и доменом, затем владельца с CLI. После входа владелец может редактировать оформление, разрешённые домены встраивания, услуги, каталог, уведомления, пользователей и промокоды. Срок действия лицензии выставляет оператор D1. [Настройки магазина](docs/BACKEND.md#новый-магазин)

## Требуется участие владельца

- Предоставить разрешение на публикацию, аккаунт Cloudflare и домен. Настроить D1, секреты, резервирование и выдачу доступа сотрудникам.
- Утвердить реальные цены, остатки, ассортимент и варианты товара. Досогласовать разрешения на недостающие материалы, которые планируется получать от производителей.
- Создать виджет Turnstile и при необходимости бота Telegram, настроить канал уведомлений и выполнить проверочную заявку. [Настройка интеграций](docs/BACKEND.md#подключение-turnstile-и-telegram)
- Согласовать условия продажи и политику данных, утверждённый рынок, процесс коммерческих лицензий и подписок. Реальные платежи потребуют отдельной интеграции и согласования.
