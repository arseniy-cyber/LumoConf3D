# Архитектура LUMO PC BUILDER

## Компоненты

| Область | Путь | Ответственность |
| --- | --- | --- |
| Витрина | `src/builder` | Подбор в каталоге, состояние сборки, режимы сцены, анализ, экспорт и заявка |
| 3D | `src/scene` | Three.js, WebGL 2, GLB и Meshopt, монтажные координаты, камера, материалы, анимации, RGB и потоки воздуха |
| Домен | `src/shared` | Типы, стартовые данные, правила проверок, оценка мощности, опубликованные замеры FPS |
| Администрирование | `src/admin` | Товары и файлы, пресеты, заявки, отчёт по заказам, настройки магазина, пользователи и аудит |
| HTTP | `functions`, `worker` | Общий обработчик для Pages и отдельного Worker, ограничение частоты, авторизация, каталог, заявки |
| Хранилище | `migrations` | Таблицы D1, ограничения, индексы, начальные данные и обновление метаданных материалов |
| Артефакты | `public`, `scripts` | Локальные исходные GLB, изображения, шрифт, команды воспроизводства и первоначальная настройка |
| Проверки | `tests` | Домен, каталог, геометрия, интерфейс и Worker с D1 |

Витрина хранит незавершённую конфигурацию и сохранённые варианты в localStorage. Ссылка может содержать состав сборки в URL или ссылаться на запись D1 с ограниченным сроком. Сведения заказа, цены и доступность проверяются на Worker по каталогу магазина. Стоимость с клиента используется для обнаружения изменений, требующих повторного подтверждения.

В сцене геометрия деталей загружается по мере использования. Процедурная геометрия применяется для позиций без локального GLB и обозначается в интерфейсе. Размеры каталога хранятся в миллиметрах. Проектные GLB используют метры с осью Y вверх. Видимая панель корпуса находится со стороны X−, передняя со стороны Z+. Для корректировки позиции товара хранятся смещение по трём осям и поворот вокруг Y. Правила посадки используют характеристики корпуса и выбранных деталей.

Магазин разрешается по hostname или параметру `store`. Записи цены, наличия, заявки, пользователя и файла относятся к конкретному магазину. Доступ к закрытым записям следует из сессии, роли и принадлежности к магазину. Загруженные публичные изображения и GLB доступны по URL. Оба варианта серверного запуска используют одни правила и таблицы. В поставляемой архитектуре GLB и фото каталога находятся в статической раздаче, новые загрузки хранятся через адаптер D1. Перенос загрузок в S3-совместимое хранилище допускает сохранение публичного маршрута и идентификаторов. [Контракт API](docs/API.md)

## Изменения и контроль версий

Общие правила совместимости импортируются напрямую и клиентом, и Worker. Добавляйте новые правила в доменный модуль и проверяйте их одинаковыми входными данными на обеих сторонах. Графические модели и материалы доступны через каталог и контроллер сцены. При развитии для других категорий товаров сохраняются маршрутизация магазина, каталога и заказов, а геометрические правила и каталог подлежат замене.
